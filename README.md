# Profiling WebAssembly with pprof and wzprof

Civo Navigate Europe 2024, 10th–11th September 2024

- Rajiv Ranjan Singh

## About

Profiling a Go program with pprof, then carrying the same workflow over to
WebAssembly with wzprof: producing CPU and memory profiles for a Wasm module and
visualizing both.
